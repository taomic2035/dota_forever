# DotA 1 玩法复刻 — 设计文档 (dota_forever)

日期: 2026-06-10 · 状态: 自主模式定稿(用户委托全权决策,事后可审阅修订)

## 0. 愿景与边界

在浏览器中完整复刻 **DotA 1 (Defense of the Ancients) 的核心玩法体验**:
5v5 三路推塔、正补/反补、战争迷雾、昼夜、符文、野区与河道 Boss、装备合成、
摧毁敌方主基地获胜。单机形态:玩家操控 1 名英雄,其余 9 名为 AI。

**复刻的是机制,不是受版权保护的内容。**
- ✅ 机制层完整复刻:WC3 数值模型(护甲公式/攻击-护甲类型克制/三属性)、
  兵线节奏、补刀经济、仇恨规则、高低地视野与 miss、兵营-超级兵、买活、TP 等。
- ❌ 不照搬 Valve/暴雪的表达:英雄名、技能名与文案、美术、音效全部原创;
  技能组仅做"机制原型致敬"并重新组合命名;阵营用原创名。
- 明确不做(v1):多人联机(架构预留确定性 lockstep 接口)、信使、幻象系、
  录像回放、地图编辑器、技能吼声配音。

## 1. 技术栈决策

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| Godot 4 | 引擎完备 | 交付需安装、自动化验证链路长 | 弃 |
| TS + PixiJS | WebGL 性能好 | 多一个依赖、API 版本漂移风险 | 弃 |
| **TS + Vite + Canvas2D** | 零运行时依赖、即开即玩、Playwright 可端到端自验证 | 渲染上限低 | **选定** |

峰值实体 ~300(兵线+英雄+建筑+野怪),Canvas2D 分层 + 地形离屏缓存足够 60fps。
测试:vitest 覆盖纯模拟核心。无任何运行时第三方依赖。

## 2. 架构

**确定性定步模拟(30Hz、种子随机、不触 DOM)与渲染(rAF + 位置插值)严格分离。**

```
src/
  core/    vec2 · 种子RNG · 数学工具
  data/    balance.ts(全部数值常量) · heroes/ · items.ts —— 纯数据
  sim/     world(tick循环+实体注册) · map(地形/寻路/视野) · unit/hero/building
           combat(伤害结算) · modifiers(buff系统) · abilities(技能执行器)
           orders(指令) · economy · ai/ · runes · neutrals · projectiles
  render/  地形层(缓存) · 实体层 · 特效层 · 迷雾层 · 小地图 · 镜头
  ui/      DOM HUD:状态条/技能栏/背包/商店/记分板/击杀播报/结算
  main.ts  装配:sim + render + input + ui
tests/     vitest:战斗矩阵/护甲/经济/寻路/视野/技能/合成
```

关键设计:
- **Modifier 系统是技能基石**:眩晕/减速/沉默/DoT/光环/属性修正一切皆 modifier,
  带来源、时长、堆叠规则、tick 钩子;技能 = 数据定义 + 行为函数。
- **Order 指令系统**:move/attack/attackmove/cast/hold/stop;人类输入与 AI 输出同构,
  天然支持未来 lockstep 联网与回放。
- 实体用 id 引用(不持有对象指针),便于序列化与确定性。

## 3. 地图

15000×15000 世界单位,64u/格 → 235×235 寻路网格。程序化中心对称构建:
- 对角河道;上/中/下三路;每路每方 3 座防御塔 + 1 对兵营(近战/远程);
  基地高台 2 塔 + 主建筑(**晨曦圣树** vs **永夜王座**)+ 泉水(回复光环+高伤防御)。
- 野区:每方 4 个普通营地 + 1 个远古营地,定时刷新(死光后整分钟刷新)。
- 河道 Boss **深渊领主**(肉山位):掉落**不灭之盾**(死亡原地复活一次),越杀越强。
- 双符文点(上/下河道),2 分钟一刷:加速/双倍/恢复/隐身。
- 秘密商店×2(高级散件);树木为阻挡物;高度 0/1/2 三层,坡道连接,
  **低打高 25% miss、低地看不见高地**(视野 LOS 采样)。

## 4. 核心数值(全部集中 `data/balance.ts`,标注"经典近似值"可调)

- 护甲减伤 = 0.06×A/(1+0.06×A);负甲增伤 = 2−0.94^|A|。
- 攻击类型 × 护甲类型矩阵:英雄/普通/穿刺/攻城/魔法 × 英雄/无甲/轻/中/重/城防
  (如:英雄攻击对城防 50%,攻城对城防 150%,穿刺对英雄 50%)。
- 属性:1 力=19HP+0.03回血;1 敏=0.14甲+1%攻速;1 智=13蓝+0.04回蓝;主属性+1 攻击。
  攻速 APS=(1+IAS)/BAT,BAT 默认 1.7,IAS 上限 +400%。英雄基础魔抗 25%。
- 等级 1–25,XP 表近似经典曲线;技能 4/4/4/3,大招 6/11/16;黄点(属性加成)×10。
- 经济:初始 603 金;工资 1 金/0.8s;正补近战兵 ~43 金、远程 ~48、攻城 ~74;
  反补:敌方 0 金 + 50% XP(本方无收益)。击杀英雄赏金 = 200+9×等级(连杀加成/终结赏金)。
- 死亡:掉金 = 30×等级(可买活,买活价 = 100+等级²×1.5 近似);复活 = 4×等级 秒。
- 兵线:开局 90s 后每 30s 一波(3 近 1 远),每 7 波 +1 投石车;每 7.5 分钟兵线成长;
  破一对兵营 → 该路超级兵;全破 → 精英兵(mega)。
- 仇恨:塔优先兵>英雄,本方英雄被攻击→塔转火攻击者;小兵优先就近敌人,
  对敌英雄 A 队友可引仇恨;脱战漂回兵线。
- 昼夜 5 分钟交替;通用视野 1800(昼)/800(夜);塔 1900;真视仅泉水/岗哨守卫。

## 7. AI(9 个 bot + 兵线/野怪/塔)

三层决策,每层独立节拍:
1. **战略层**(~1s):评估分路/推线/守塔/打野/回城/参团/撤退,输出"意图"。
2. **战术层**(~0.3s):意图→具体目标;技能按 tags + 法力/冷却/射程启发式释放;
   血量阈值撤退,塔下仇恨规避。
3. **微操层**(每 tick):补刀计时(预测兵血到达攻击点伤害)、反补、走 A、撤退路径。
难度旋钮:反应延迟、补刀精度、参团意愿。兵线 AI 按 WC3 仇恨表;野怪驻留营地、脱战回拉满血。

## 8. 渲染与 UI

- 四层画布:地形(离屏一次性烘焙) / 单位+弹道+特效 / 迷雾(低分辨率 offscreen,
  destination-out 挖洞,放大柔化) / DOM HUD。
- 美术:程序化矢量绘制——单位为几何轮廓+队伍色+朝向指示,英雄各有独特图形;
  风格定位"清晰可读的战棋感",不追写实。
- HUD:顶栏(时间/昼夜图标/比分/金钱)·底部中央(头像/等级/属性/血蓝条/4 技能位+黄点/6 格背包+储藏)
  ·右下小地图(迷雾+单位点+信号 ping)·商店面板(分类页签+合成树)·击杀播报·Tab 记分板·结算画面。
- 操作(忠实 1 代):右键移动/攻击,A 点地攻击移动,QWER 施法,S 停止,H 保持,
  Tab 记分板,空格回看主英雄,Alt 点小地图信号;框选仅主英雄(单英雄操控)。
- 音频:WebAudio 程序化合成(攻击命中/施法/升级/击杀播报音/背景白噪环境),无外部素材。

## 9. 测试与验证

- vitest 单测:伤害矩阵/护甲公式/负甲/经济曲线/XP 升级/寻路可达性与对称性/
  视野 LOS/modifier 堆叠/技能状态机/合成树完整性(所有配方可达、价格=部件和)。
- 端到端:Playwright 启动 bot 对局 + 时间加速,断言"兵线交战发生/一血出现/
  塔被摧毁/比赛可分胜负",截图归档 `docs/screenshots/`。
- 性能预算:模拟 tick ≤ 8ms,渲染帧 ≤ 16ms(满场)。
- 内置自测模式:`?mode=spectate&speed=8` 观战快进,作为持续冒烟测试。
