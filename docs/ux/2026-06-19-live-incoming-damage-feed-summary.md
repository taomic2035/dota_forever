# 实时受伤来源提示(务实版战斗日志)

日期: 2026-06-19
范围: 战斗中实时显示「谁正在打你 + 伤害量」(对应 hook 点的"战斗日志"诉求的高价值子集)。

## 背景

完整战斗日志面板是用户保留的"大方向"。但其中**最高价值、可立即复用已有基础设施**的部分,是实时受击威胁提示:战斗中即时看到伤害来源 → 判断撤退/反打。死亡回顾(V2/V3)已建 `DamageLog`(每帧累积玩家受伤,按来源聚合),实时提示直接复用,几乎零新逻辑。

## 方案

- `DamageLog.lastAt()`:最近受伤时间戳,判断"是否正在战斗"。
- main:`hero.alive && world.time - damageLog.lastAt() < 3` 时,`hud.incomingDamage = damageLog.recap(4, 4)`(近 4s 受伤按来源聚合,top4);否则空。
- HUD:左侧 `combatFeed` 面板,显示「⚠ 正在受到伤害」+ 来源行(名字 + 伤害总量 + 物理橙/魔法紫/纯粹白分段条);无近期受击自动隐藏。

## 验证

- typecheck 通过;完整套件 0 失败;`deathRecapModel.test` +1(lastAt)。
- 真实运行:英雄受小兵攻击时左侧显「⚠ 正在受到伤害 · 小兵 77」;远离 >3s 后自动隐藏;0 错误。
