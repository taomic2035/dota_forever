## 框架(纯插管,非创意;镜像现有神杖 `hasScepter`)

- 物品 `aghanims_shard`(1400 金,消耗品 charges:1):使用 → `heroMeta.shard=true`(永久),消耗。
  - V1 用「购买后点击使用激活」(与知识之书同款消耗品流程);DotA 是购买即生效,后续可加购买钩子自动激活。
- `hasShard(u) = u.isHero() && u.heroMeta?.shard === true`(`src/sim/abilities.ts`,紧邻 `hasScepter`)。
- `AbilityDef.shard?: { desc: string }`(`types.ts`,紧邻 `scepter?`):仅声明 UI 描述;行为走各英雄 `onCast/orbOnHit` 里的 `if (hasShard(caster)) {…}` 分支(与神杖行为轴一致)。
- `HeroMeta.shard: boolean`(`unit.ts`,init `false`)。

## 4 个展示英雄提案(原创 · 非大招级 · 可 batchsim 验证)

### 雷恩·铁壁(坦克先手)— 强化 W「裂石战吼」
- **效果**:战吼现在**软驱散**范围内友军身上的减益(减速/缴械等非硬控负面),为团队提供反先手解控。
- **实现轴**:W `onCast` 中 `if (hasShard) for 范围友军 purge(w, ally, false, false)`(基础驱散:解负面、不解硬控)。复用现有 `purge`。
- **理由**:契合「铁壁」守护主题;给坦克一个团队工具而非个人爆发,平衡温和。

### 莉雅·霜语者(控制法师)— 强化 W「冰封禁制」
- **效果**:冰封结束的瞬间,在目标位置引爆**小型冰霜新星**(范围 300:魔法伤害 + 1.5s 减速 25%),把单体控制延伸为小团控。
- **实现轴**:`liya_bind_root` modifier 加 `onExpire`(已有该回调机制),内部 `damageArea + modifierArea`(liya 已导入)。
- **理由**:呼应连锁寒霜;延展不喧宾夺主(伤害取中等)。

### 艾莉·疾风射手(敏捷核心)— 强化 Q「霜寒之箭」
- **效果**:对**已处于减速状态**的敌人,霜寒之箭额外造成相当于艾莉敏捷 X%(提案 60%)的魔法伤害(寒霜碎裂)。
- **实现轴**:Q `orbOnHit` 中 `if (hasShard && 目标含 bonusMoveSpeedPct<0 的 modifier) spellDamage(agi*0.6)`。
- **理由**:纯数值爆发、无新增控制 → 平衡可控;奖励「先减速再收割」的连招。

### 佐拉·雷霆先知(全图法师)— 强化 W「裁决天雷」
- **效果**:天雷命中后**弹射**至 600 范围内 1 个额外敌方英雄(造成 60% 伤害,无眩晕)。
- **实现轴**:W `onCast` 中 `if (hasShard)` 用 `queryRadius` 找次目标再 `spellDamage(BOLT*0.6)`。
- **理由**:小幅 AoE 延展,契合「连环/全图」主题;不触及大招级强度。
