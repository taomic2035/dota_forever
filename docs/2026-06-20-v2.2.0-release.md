## 本版交付

### 模拟层深化(Opus)
- **单位碰撞 / body-block**(`sim/collision.ts`):此前缺失(单位互穿)。确定性两阶段 Jacobi 分离,启用卡兵控线 / 拦截 / 绕单位 juke。关键调参:单 tick 分离上限防甩飞、站桩攻击单位不被挤散保攻城吞吐。
- **幻象继承完整面板** + **暴击伪随机(PRD)**:幻象取源英雄 calc 快照(含装备);PRD 反解常数消除极端运气,**均值守恒→平衡不变**。
- **经济保真(对照 DotA)**:
  - **助攻金「赏金切出式」**——有助攻者时赏金切出 `0.4` 在助攻者间均分、击杀者得剩余;**每次击杀总注入恒 = 赏金 = 基线经济 → 零净值通胀**。(关键发现见下。)
  - 幻象死亡金、**Roshan 奶酪**(第 2 次击杀起掉、即时回 2500HP+1000MP)。

### 操控 UX / HUD 大整合(Codex)
共享可用性 API、施法预览 V2、子组循环/双击同类选择、物流面板 V2、信使指令 V2、沟通层(聊天轮盘/顶栏 ping/团队日志)、buff 图标+控制条、威胁方向、商店 V2、小地图通信、观战调试 UX、新手引导+控制预设——均纯函数 model + TDD,渲染/模拟严格分离。

### 地图机制可读性(Codex)

### Bot AI
bot 战斗中使用主动物品(妖术/orchid/dagon 自保 BKB);续航/游走类经 batchsim 否决(拖死决胜节奏)。

## 关键发现 / 沉淀的铁律

> **决胜闸门 vs DotA 保真度的根本张力**:本 sim 的 bot **靠高击杀率收尾**;**任何降低「击杀→目标」转化率的改动都会让 bot 收不掉尾 → 90min 平局 → 破 8/8**。本版 batchsim 闸门**反复拦下**:叠加式助攻金(增净值)、树木 LOS 视野(减视野)、攻击前摇 IAS 独立(减有效攻击)、新增地图拓扑(高地/森林改 height/可走)。

由此确立两条工程铁律(已写入 CHANGELOG / handoff):
1. **视觉丰富 = 免费**(纯渲染不碰 sim);**拓扑/攻击/视野等降击杀率的改动 = 平衡敏感**,每改必 batchsim 8/8。
2. 净中性改造可安全落地(助攻金「切出而非叠加」即范例);会降击杀率的保真改造**需 bot 收尾 AI 配套**,否则破决胜。
3. 「高地约等于没有」类反馈多为**可见性(渲染)问题**,非「缺机制」——优先渲染现有机制,而非新增拓扑。

`tests/mapIntegrity.test.ts` 现守护地图拓扑约束(锚点保持 sim height 1、不碰关键轴线)。

## 多 agent 协作

Opus(sim/机制/平衡 QA)↔ Codex(UX/视觉/地图可读性)同一工作树并行。典型闭环:Codex 加地图高地拓扑 → Opus batchsim 抓到破 8/8(6/8)→ Codex 转为纯视觉锚点 → Opus 整合树复验回 8/8。分工:**sim/拓扑归 Opus 把平衡关,视觉/渲染归 Codex**;共享文件按区块各改。
